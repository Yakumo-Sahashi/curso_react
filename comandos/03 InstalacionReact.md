# React JS

## ¿Qué es React JS?

React es una libreria o biblioteca de **JavaScript** de código abierto enfocada en la creación de interfaces de usuario interactivas. Fue desarrollada por **Facebook (Meta)** y es ampliamente utilizada ya que permite a los desarrolladores construir componentes reutilizables que forman la base de las interfaces de usuario, lo que facilita el desarrollo de aplicaciones web y móviles.

---

## Ventajas

- Desarrollo rápido y eficiente
- Alto rendimiento con Virtual DOM
- Compatible con múltiples plataformas
- Gran ecosistema y comunidad activa
- Popularidad y demanda laboral
- Integración con tecnologías modernas

---

## Instalacion de React JS

### 1. Requisitos

* Node js (version actual).
* Conocimientos en JavaScript.
* Conocimientos en EcmaScript.
* Visual Studio Code.
* * ES7+ React/Redux/React-Native snippets
* * Prettier
* * React Developer Tools

---

### 2. Instalación global de React
```bash
npm i -g create-react-app
```

---

### 3. Crear un nuevo proyecto
```bash
npx create-react-app nombrProyecto
```

---

### 4. Lanzar el proyecto
```bash
cd nombreProyecto/
npm start
```
**Resultado: http://localhost:3000**

***Nota: Solucion a posible error:***
En caso de arrojar un error usar el comando
```bash
npm i web-vitals --save-dev
```
